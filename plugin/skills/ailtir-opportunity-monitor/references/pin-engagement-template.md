### Recommended Pre-Market Engagement Actions

The following actions are recommended during the engagement window before RFQ publication:

1. **Technical Site Visit / Briefing Day** — If the authority holds a pre-market engagement event, attend. These are common for CWMF Gate 1 projects.
2. **RFI Submission** — Submit a Request for Information to the authority's procurement office expressing interest and asking about the procurement timeline and evaluation criteria.
3. **Stakeholder Mapping** — Identify the key decision-makers: Procurement Officer, Project Manager, Technical Advisor (Architect/Engineer). Map relationships.
4. **Case Study Preparation** — Prepare a targeted case study from a comparable prior project to share at any pre-market briefing.
