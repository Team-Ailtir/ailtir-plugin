# Contractual Notice Templates

Use these structures when drafting formal notices.

## 1. PW-CF (Public Works) - Notice of Delay
**Reference:** Clause 9.3 (Delay and Extension of Time)
**Time Bar:** 20 working days from when the Contractor became aware (or should have become aware) of the delay.

**Structure:**
- State clearly that this is a notice under Clause 9.3.
- Describe the Compensation Event (referencing the specific item in Schedule Part 1K).
- State the date the event occurred.
- Provide an initial estimate of the delay to the Date for Substantial Completion.
- Note that full particulars will follow within the required 20 working days.

## 2. PW-CF (Public Works) - Notice of Claim for Additional Cost
**Reference:** Clause 10.3 (Claims for Additional Cost)
**Time Bar:** 20 working days.

**Structure:**
- State clearly that this is a notice under Clause 10.3.
- Describe the Compensation Event.
- State the date the event occurred.
- Note that full particulars of the cost will follow.

## 3. RIAI 2025 - Notice of Delay
**Reference:** Clause 30
**Time Bar:** 10 working days.

**Structure:**
- State clearly that this is a notice under Clause 30.
- Describe the event causing delay.
- State the expected impact on the Date for Practical Completion.
